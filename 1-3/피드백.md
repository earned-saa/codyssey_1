# 내 피드백 정리

## 잘된 점 ✅

- 영화를 선택해서 드래그앤드롭 혹은 클릭으로 이동이 가능합니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- '처음으로'를 누르면 처음 영화 8개가 모두 미분류로 돌아가고 새로 추가한 카드도 사라집니다.
- 외부 파일이나 로그인 없이 HTML 한 장으로 열립니다.
- 몇 개 중 몇 개를 분류했는지 알 수 있습니다.
