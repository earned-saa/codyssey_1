# 변화의 삼각형

---

## 대상 사용자

- 회피형 성향의 개인
- 감정을 직면하기보다 회피하는 경향이 있는 사람
- 방어감정(수치심, 불안감, 죄책감)으로 진정한 감정을 덮는 패턴을 가진 사람
- 자신의 감정 패턴을 인식하고 싶은 사람

---

## 사용 목적

- 현재 느끼는 감정과 상황을 구체적으로 기록하기
- 방어감정 아래의 핵심감정 인식하기 (수치심/불안감/죄책감 → 그 아래 숨겨진 감정 찾기)
- 자신이 어떤 행동(방어기제)으로 감정을 회피하는지 알아차리기
- 감정 패턴의 변화를 추적하고 자신의 감정 회피 패턴 인식하기

---

## 화면 구성과 동작

### 페이지1: 온보딩
- AEDP 이론 및 변화의 삼각형 개념 설명 텍스트
- 변화의 삼각형 다이어그램 이미지 표시
- 회피형 성향 사용자를 위한 가이드 설명
- 앱 사용 방법 안내
- **[시작하기] 버튼** 클릭 → 페이지2로 이동

---

### 페이지2: 일일 감정 기록 (핵심)

#### 레이아웃 순서 (위 → 아래)

```
① 입력 폼
② 📊 감정 패턴 돌아보기 (통계 섹션)
③ 📋 저장된 감정 기록 (기록 카드 목록)
```

---

#### ① 입력 폼 (페이지 맨 위에 항상 표시)

**1단계: 상황 입력**
- 텍스트박스 (textarea)
- 입력 안내 문구를 label로 분리 표시 (placeholder 줄바꿈 문제 방지)
- 안내 예시: "상사가 내 의견을 무시했다", "친구가 늦게 왔다"

**2단계: 억제감정 선택 (3가지)**
- 체크박스 3개: 수치심 / 불안감 / 죄책감
- **중복 선택 가능**
- 회피형이 먼저 느끼는 방어감정

**3단계: 핵심감정 선택 (7가지)**
- **체크박스 7개 (중복 선택 가능)** ← v2.0에서 radio → checkbox로 변경
- 두려움 / 분노 / 슬픔 / 기쁨 / 흥분 / 혐오 / 성적 흥분
- 억제감정 아래 숨겨진 진정한 감정
- 저장 시 **배열(Array)** 형태로 로컬스토리지에 저장
- 기록 카드에 **여러 태그**로 표시

**4단계: 방어기제 선택 (32개, 3가지 카테고리)**
- 탭 또는 드롭다운으로 3가지 카테고리 분류
  - **카테고리1 (원시적 방어):** 부인, 억압, 투사, 치환, 전위, 반동형성, 해리, 격리
  - **카테고리2 (신경증적 방어):** 합리화, 지적화, 유머화, 승화, 보상, 동일시, 이상화
  - **카테고리3 (미성숙 방어):** 회귀, 행동화, 신체화, 투사적 동일시, 분열, 왜곡, 망상
- 한글화 완료 (32개 전체)
- 감정을 피하기 위해 취한 행동/생각 패턴 선택

**5단계: 저장하기**
- **[저장] 버튼** 클릭 → 로컬스토리지에 저장 → 입력 폼 초기화
- 저장 후 통계 섹션 **자동 갱신** (`renderStats()` 호출)

---

#### ② 감정 패턴 돌아보기 (통계 섹션)

> 기록 카드 목록 **바로 위**에 위치

- **억제감정 / 핵심감정 / 방어기제** 3개 카드로 구성
  - 억제감정·핵심감정: 2열 나란히 배치
  - 방어기제: 전체 너비(2열 병합)
- 각 카드 내부: **가로 바 차트** (선택 빈도 시각화)
  - 바 길이 = 최댓값 대비 상대 비율
  - 오른쪽 끝에 횟수 숫자 표시
- **[표 파일로 내보내기]** 버튼 → CSV 파일 다운로드 (UTF-8 BOM 포함)
- **[기록 인쇄 / PDF 저장]** 버튼 → `window.print()` 호출
- 하단 안내 문구: "빈도는 선택한 횟수일 뿐 감정의 강도나 심리 상태를 진단하지 않아."
- 기록 저장·삭제 시 **자동 갱신**


#### ③ 저장된 감정 기록 (기록 카드 목록)

- 최신 기록이 맨 위에 표시 (역순)
- 각 기록 카드에 표시되는 정보:
  - 기록 시간 (예: 2024-01-15 오후 2:30)
  - 상황 요약 (입력한 텍스트)
  - 선택한 억제감정 태그
  - 선택한 핵심감정 태그 **(여러 개 가능)**
  - 선택한 방어기제 태그
  - **[삭제] 버튼** → 해당 기록 삭제 + 통계 자동 갱신

## 기술 스택

| 항목 | 내용 |
|---|---|
| 파일 구성 | **단일 HTML 파일** (HTML + CSS + JS 인라인) |
| 데이터 저장 | 브라우저 **LocalStorage** |
| 외부 의존성 | 없음 (순수 HTML/CSS/JS) |
| 반응형 | 모바일/데스크톱 대응 (`@media max-width: 600px`) |

---

## 완료 기준

- 상황 입력 후 저장 → 기록 목록에 즉시 표시됨
- 억제감정 **중복 선택** 후 저장 → 기록 카드에 여러 태그로 표시됨
- 핵심감정 **중복 선택** 후 저장 → 기록 카드에 여러 태그로 표시됨
- 방어기제 선택 후 저장 → 기록 카드에 표시됨
- 저장/삭제 시 → **통계 섹션 자동 갱신**됨
- 감정 기록을 다수 실행하면 감정 패턴 통계로 기록이 보여짐
- **[표 파일로 내보내기]** → CSV 파일이 정상 다운로드됨
- 페이지 새로고침(F5) 후 → 모든 기록 유지됨
- 브라우저 종료 후 재접속 → 모든 기록 유지됨
- LocalStorage에 JSON 배열 형식으로 정확히 저장됨
- HTML 파일 하나로 열림 (로그인·서버 불필요)

## 추가 기능 (미구현 — 향후 개발)

- 신체 반응 체크리스트 (긴장, 가슴 답답함, 목 조임 등)
- 기록에 태그 추가 (상황 유형별 분류)
- 기록 검색 기능
- 기록 내보내기 PDF 고도화

---

## 한계 및 비목표

1. 의료 진단 도구가 아님 (심리 치료 대체 불가)
2. 회원 가입/로그인 기능 없음
3. 클라우드 동기화 없음 (한 기기에서만 데이터 접근 가능)
4. 브라우저 캐시 삭제 시 모든 기록 소실 가능
5. 다중 기기 동기화 불가능

---

## 검증 방법

- 상황 입력 후 저장 → 기록 목록에 표시되는지 확인
- 억제감정/핵심감정 **여러 개** 선택 후 저장 → 기록 카드에 **모두** 표시되는지 확인
- 방어기제 선택 후 저장 → 기록 카드에 정확히 표시되는지 확인
- 저장/삭제 후 → **통계 바 차트가 즉시 갱신**되는지 확인
- **[표 파일로 내보내기]** → CSV 열·값이 정확한지 확인
- 페이지 새로고침 후 → 데이터 유지 확인
- 브라우저 개발자도구 → Application → LocalStorage → JSON 형식 확인
- 브라우저 종료 후 재접속 → 이전 기록 복구 확인
- 여러 기록 추가 후 → 최신순 정렬 확인
- 삭제 버튼 클릭 → 목록·LocalStorage 양쪽에서 삭제 확인
