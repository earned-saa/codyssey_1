## 좁혀서 적은 한 문장
**띄어쓰기가 있는 영화 카드만 드래그가 안 되는 이유는 `data-id` 속성에 따옴표가 없어서 HTML이 제대로 파싱되지 않기 때문이다.**

## 좁히려고 해 본 것과 결과

| 시도 | 결과 |
|------|------|
| 띄어쓰기 없는 영화(기생충) vs 있는 영화(센과 치히로의 행방불명) 비교 | 두 경우의 차이점 발견 ✅ |
| 개발자도구 요소검사로 HTML 구조 확인 | `data-id=` 뒤 따옴표 누락 확인 ✅ |
| 클릭은 되는데 드래그만 안 되는 이유 분석 | 드래그는 `data-id` 속성값을 필요로 하기 때문 파악 ✅ |

## AI가 말한 원인과 그 설명을 직접 확인한 결과

### AI의 설명
data-id= 뒤에 따옴표가 없음
→ 띄어쓰기가 없으면: data-id=기생충 (괜찮음)
→ 띄어쓰기가 있으면: data-id=센과 치히로의 행방불명 (HTML 파서가 "센과"까지만 읽음)
→ 결과: data-id 속성이 제대로 저장 안 됨
→ 드래그할 때 event.dataTransfer.getData()가 빈 값을 가져옴

### 직접 확인한 결과
**개발자도구 콘솔에서 확인:**
```javascript
// 띄어쓰기 없는 영화
document.querySelector('[data-id="기생충"]')?.dataset.id
// 결과: "기생충" ✅

// 띄어쓰기 있는 영화 (수정 전)
document.querySelector('[data-id="센과 치히로의 행방불명"]')?.dataset.id
// 결과: undefined ❌ (찾을 수 없음)
개발자도구 요소검사에서 확인:

기생충: <button data-id=기생충> ✅
센과 치히로의 행방불명: <button data-id=센과 치히로의 행방불명> ❌ (따옴표 없음)
결론: AI의 설명이 정확했다! ✅
