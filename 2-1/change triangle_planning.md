# 변화의 삼각형

## 대상 사용자

- 회피형 성향의 개인
- 감정을 직면하기보다 회피하는 경향이 있는 사람
- 방어감정(수치심, 불안감, 죄책감)으로 진정한 감정을 덮는 패턴을 가진 사람
- 자신의 감정 패턴을 인식하고 싶은 사람

## 사용 목적

- 현재 느끼는 감정과 상황을 구체적으로 기록하기
- 방어감정 아래의 핵심감정 인식하기 (수치심/불안감/죄책감 → 그 아래 숨겨진 감정 찾기)
- 자신이 어떤 행동(방어기제)으로 감정을 회피하는지 알아차리기
- 감정 패턴의 변화를 추적하고 자신의 감정 회피 패턴 인식하기

## 화면 구성과 동작

### 페이지1: 온보딩
- AEDP 이론 및 변화의 삼각형 개념 설명 텍스트
- 회피형 성향 사용자를 위한 가이드 설명
- 앱 사용 방법 안내
- [시작하기] 버튼 클릭 → 페이지2로 이동

### 페이지2: 일일 감정 기록 (핵심)

#### 입력 폼 (페이지 맨 위에 항상 표시)

**1단계: 상황 입력**
- 텍스트박스: "감정이 발생한 상황을 입력하세요"
- 예시: "상사가 내 의견을 무시했다", "친구가 늦게 왔다"

**2단계: 억제감정 선택 (3가지)**
- 체크박스 3개: 수치심 / 불안감 / 죄책감
- 중복 선택 가능
- 회피형이 먼저 느끼는 방어감정

**3단계: 핵심감정 선택 (7가지)**
- 라디오 버튼 또는 체크박스 7개
- 슬픔 / 분노 / 두려움 / 외로움 / 취약함 / 수치심 / 죄책감
- 억제감정 아래 숨겨진 진정한 감정

**4단계: 방어기제 선택 (32개, 3가지 카테고리)**
- 드롭다운 또는 탭으로 3가지 카테고리 분류
  - 카테고리1: 부인, 억압, 투사, 치환, 전위, 반동형성, 해리, 격리
  - 카테고리2: 합리화, 지적화, 유머화, 승화, 보상, 동일시, 이상화
  - 카테고리3: 회귀, 행동화, 신체화, 투사적 동일시, 분열, 왜곡, 망상
- 감정을 피하기 위해 취한 행동/생각 패턴 선택

**5단계: 저장하기**
- [저장] 버튼 클릭 → 로컬스토리지에 저장 → 입력 폼 초기화

#### 기록 목록 (입력 폼 아래)
- 최신 기록이 맨 위에 표시 (역순)
- 각 기록 카드에 표시되는 정보:
  - 기록 시간 (예: 2024-01-15 14:30)
  - 상황 요약 (입력한 텍스트)
  - 선택한 억제감정 (수치심, 불안감 등)
  - 선택한 핵심감정 (분노, 외로움 등)
  - 선택한 방어기제 (합리화, 회귀 등)
  - [삭제] 버튼 (선택사항)

## 필요한 자료

- AEDP 이론 설명 텍스트 (온보딩 페이지용)
- 변화의 삼각형 개념 설명 및 이미지
- 억제감정 3가지 정의 및 설명
- 핵심감정 7가지 정의 및 설명
- 방어기제 32개 분류 및 설명
- 회피형 성향 설명 및 가이드

## 완료 기준

- 상황 입력 후 저장 버튼 클릭 → 기록 목록에 즉시 표시됨
- 억제감정 선택 후 저장 → 기록 카드에 선택한 감정이 표시됨
- 핵심감정 선택 후 저장 → 기록 카드에 선택한 감정이 표시됨
- 방어기제 선택 후 저장 → 기록 카드에 선택한 방어기제가 표시됨
- 페이지 새로고침 (F5) 후 → 입력한 모든 기록이 그대로 유지됨
- 브라우저 개발자도구 (F12) → Application → LocalStorage에서 → JSON 형식으로 데이터가 정확히 저장되어 있음
- 브라우저 완전히 닫은 후 다시 열기 → 이전에 입력한 모든 기록이 유지됨
- HTML 파일 하나로 열림 (다른 파일이나 로그인 없이 작동)

## 추가 기능

- 신체 반응 체크리스트 (긴장, 가슴 답답함, 목 조임 등)
- 기록에 태그 추가 (상황 유형별 분류)
- 기록 검색 기능
- 감정 빈도 차트 및 방어기제 통계 시각화
- 기록 내보내기 (CSV/PDF)

## 한계 및 비목표

1. 의료 진단 도구가 아님 (심리 치료 대체 불가)
2. 회원 가입/로그인 기능 없음
3. 클라우드 동기화 없음 (한 기기에서만 데이터 접근 가능)
4. 데이터 분석 및 장기 감정 패턴 시각화 불가능 (로컬스토리지 제약)
5. 브라우저 캐시 삭제 시 모든 기록 소실 가능
6. 다중 기기 동기화 불가능

## 검증 방법

- 상황 입력 후 저장 → 기록 목록에 표시되는지 확인
- 억제감정/핵심감정/방어기제 선택 후 저장 → 기록 카드에 정확히 표시되는지 확인
- 페이지 새로고침 후 → 데이터가 유지되는지 확인
- 브라우저 개발자도구에서 LocalStorage 확인 → 데이터가 JSON 형식으로 저장되어 있는지 확인
- 브라우저 종료 후 재접속 → 이전 기록이 모두 복구되는지 확인
- 여러 기록 추가 후 → 최신순으로 정렬되어 표시되는지 확인
- 삭제 버튼 클릭 → 해당 기록이 목록에서 제거되고 LocalStorage에서도 삭제되는지 확인
