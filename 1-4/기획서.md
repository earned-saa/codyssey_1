# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.
- 각 영화마다 50자 내외의 짧은 감상을 남깁니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 각 영화 카드 옆에는 감상 입력창이 항상 표시됩니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 '추가'를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록, 등급 배치, 감상을 브라우저에 자동으로 저장합니다.
- '처음으로'를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화, 등급, 감상이 모두 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- '처음으로'를 누르면 처음 영화 8개가 모두 미분류로 돌아가고 감상도 모두 지워집니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.
- 각 영화 카드 옆에 감상 입력창이 항상 표시됩니다.
- 감상은 50자 내외(최대 100자)로 입력할 수 있습니다.
- 감상을 입력하면 자동으로 저장됩니다.
- 감상 입력창에 현재 글자 수를 표시합니다.

## 주요 기능

### 1. 영화 등급 분류
- S, A, B, C 네 개의 등급 칸이 있습니다.
- 카드를 선택한 후 등급 글자를 누르거나 카드를 끌어서 등급 칸으로 옮깁니다.
- 한 영화는 한 칸에만 속합니다.

### 2. 감상 입력
- 각 영화 카드 옆에 감상 입력창이 항상 표시됩니다.
- 50자 내외(최대 100자)의 짧은 감상을 입력할 수 있습니다.
- 글자 수를 실시간으로 표시합니다.
- 감상은 자동으로 저장됩니다.

### 3. 영화 추가
- 제목 입력창에 영화 제목을 입력하고 '추가' 버튼을 누르면 새 카드가 생깁니다.
- 새 카드는 '아직 안 정한 영화' 섹션에 추가됩니다.
- 같은 제목의 영화는 중복으로 추가할 수 없습니다.

### 4. 저장 및 복원
- 영화 목록, 등급 배치, 감상이 모두 로컬스토리지에 자동으로 저장됩니다.
- 같은 브라우저에서 파일을 다시 열면 이전 상태가 복원됩니다.
- 다른 브라우저나 다른 기기에서는 저장된 내용이 보이지 않습니다.

### 5. 초기화
- '처음으로' 버튼을 누르면 처음 영화 8개가 모두 미분류 상태로 돌아갑니다.
- 모든 감상도 함께 지워집니다.

## 반응형 디자인

- 데스크톱: 영화 카드와 감상 입력창이 가로로 나란히 표시됩니다.
- 모바일: 영화 카드와 감상 입력창이 세로로 배치됩니다.
- 모든 화면 크기에서 내용이 잘리지 않고 볼 수 있습니다.

## 기술 스택

- HTML5
- CSS3 (Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- 로컬스토리지 (localStorage)
