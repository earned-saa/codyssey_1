# 미션 4 기록

## 사용한 AI 기록/주요 대화 캡처 파일 명
- Claude Haiku 4.5 / 미션4 대화
## 더한 기능과 고른 이유

### 1. 감상 입력 기능
**이유:** 영화를 등급으로만 나누는 것보다 개인적인 생각을 기록하면 나중에 왜 이 등급을 줬는지 기억할 수 있고, 친구들과 공유할 때도 감상까지 함께 보여줄 수 있음

**구현:** 각 영화 카드 옆에 감상 입력창 배치 → 50자 내외 제한 → 실시간 글자 수 표시 → 입력 시 자동 저장

## 받은 파일, 맞지 않은 완성 기준, 그래서 한 일

### 받은 파일의 문제점
1. **감상 입력창이 카드 옆에 안 남음** ❌
   - 감상을 입력해도 화면에서 사라짐
   - 새로고침하면 감상이 보이지 않음


### 맞지 않은 완성 기준
| 기준 | 상태 |
|------|------|
| 감상이 카드 옆에 항상 표시 | ❌ |
| 감상 자동저장 | ❌ |
| 감상 입력창 UI 정확성 | ❌ |

### 그래서 한 일 (완성)

**1단계: 구조 수정**
- 감상 입력창과 카드를 하나의 컨테이너로 묶음
- Flexbox로 가로 배치 설정

**2단계: CSS 스타일링**
- `.card-item { display: flex; gap: 8px; }` 로 카드와 감상을 나란히 배치
- 모바일에서는 `flex-direction: column;` 으로 세로 배치

**3단계: 자동저장 기능 확인**
- textarea 입력 이벤트마다 상태 업데이트
- 로컬스토리지에 즉시 저장
- 새로고침해도 감상이 유지됨

**4단계: 글자 수 표시 추가**
- 실시간으로 "현재/100" 형태로 표시
- 50자 이상 입력 시 경고 표시

**5단계: 기획서 재작성**
- 감상 기능을 기본 기능으로 포함
- 완성 기준에 감상 관련 항목 추가

## 주요 학습 포인트
1. **레이아웃 구조** - 데이터와 UI를 함께 고려한 설계 필요
2. **반응형 디자인** - Flexbox와 미디어 쿼리 활용
3. **자동저장 패턴** - 입력 이벤트마다 상태 업데이트 → 저장
4. **사용자 경험** - 감상이 항상 보여야 사용자가 쉽게 입력 가능
